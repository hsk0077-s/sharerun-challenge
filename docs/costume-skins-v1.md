## 2. 동작 규칙
- **구매(서버 기준)**: 세트는 구성품 각각의 `shopInventory` 문서를 만든다(세트 자체 문서는 없음, `fromBundle`에 세트 id). 지출 기록은 한 건. **구성품을 하나라도 이미 가졌으면 세트는 400으로 거절**하고 아무것도 청구하지 않는다(남은 버전은 단품으로 산다. 앱은 안내 문구를 보여 준다).
- **동물 착용**: `outfit` 칸. 운동복을 입으면 낱개 상의·하의·신발이 빠지고, 낱개 옷을 입으면 운동복이 빠진다(서버·앱 같은 규칙). 손·눈·등·머리 소품은 그대로 겹친다. 머리 칸은 낱개 모자가 운동복의 머리 그림보다 앞선다. 스킨은 기존대로 통째로 대체.
- **캐릭터 착용**: `costume` 칸(서버 `accessory_loadout`에 저장). 서버가 **산 것인지, 캐릭터용인지, 프로필 성별과 맞는 버전인지**를 검사한다(공용은 누구나). 세트는 입을 수 없다. 성별을 바꿔도 산 버전은 보유 목록에 남고, 맞지 않는 버전은 화면에서 잠금 표시(홈 아바타는 기본 그림으로 돌아감). 성별을 되돌리면 다시 입혀진다.
- **홈 아바타**: 기본 남/여 그림을 고른 경우에만 산 의상이 입혀진다(`AvatarPresets`의 남/여 선택은 그대로). 아바타 고르기 창에 "의상" 칸이 생기고 **산 의상만** 보인다.
- 상점 꾸미기 탭에 `운동복`, `캐릭터 의상` 칸이 생겼고 세트 카드에는 "세트" 표시가 붙는다.
- 상품명 11개 언어: `lib/l10n/accessory_names.dart`, `lib/features/accessories/accessory_names.dart`. 한글 앱 이름 "쉐어런"을 상품명에 쓰지 않았고 금지어(월드컵·올림픽·FIFA·IOC·브랜드 이름) 검사 테스트가 있다.

## 3. 실제 그림이 필요한 목록 (디자이너용)
같은 파일 이름으로 덮어쓰면 코드 수정 없이 반영된다(자리표시 생성기: `python3 tool/gen_costume_placeholders.py`, 덮어쓰기에 주의). 모든 그림 **1024×1024**, 기존 소품과 같은 판(위치 계산 없이 겹침), 형식 `.webp`.
### 3-1. 동물 운동복 파츠 — 100장 (투명 바탕, 해당 칸 옷만)
경로 `assets/images/accessories/outfit/<파일>-<칸>-<동물>.webp`, 동물 5종 `turtle, beagle, wolf, zebra, cheetah`.
| 파일 | 칸 | 장수 |
|---|---|---|
| `soccer` | top, bottom, feet | 15 |
| `singlet` | top, bottom, feet, head(머리띠) | 20 |
| `basketball` | top, bottom, feet | 15 |
| `baseball` | top, bottom, feet, head(모자) | 20 |
| `badminton` | top, bottom, feet, head(바이저) | 20 |
| `taekwondo` | top(도복 상의+흰 띠), bottom | 10 |
동물별 주의: 거북이 등껍질, 비글·늑대·얼룩말·치타 귀와 모자 충돌, 꼬리 구멍, 얼룩말 줄무늬와 색 대비.
### 3-2. 캐릭터 의상 — 20장 (불투명, 상반신, 기존 `avatar_gender_{male,female}.png`과 같은 구도)
경로 `assets/images/characters/costume/<파일>-<male|female>.webp`
- 운동복 6종 × 남·여 = 12장: `soccer, singlet, basketball, baseball, badminton, taekwondo`
- 전통의상 4종 × 남·여 = 8장: `hanbok, yukata, aodai, bavaria` (남: 저고리+바지 / 유카타 짙은 단색+좁은 띠 / 아오자이 남 / 레더호젠, 여: 저고리+치마 / 화사한 무늬+넓은 띠 / 아오자이 여 / 디른들)
**합계 120장.** 세트(`*B`, `*S`)는 구성품 그림을 쓰므로 별도 그림이 없다.

## 4. 그림 규칙 (명세서와 같음)
FIFA·올림픽·IOC·국가대표·실제 구단 엠블럼·브랜드 표식(삼선, 스우시 등) 금지, 쉐어런 자체 문양과 배색만. 실존 인물·왕 이름, 실제 문장·휘장, 종교 장식, 원주민 머리장식 금지. 유카타에 일본 가문 문장 금지. 태권도 도복에 협회·대회 로고 금지, 띠는 흰 띠 하나. 이름은 "국가 + 지역" 형식.
