# iOS 실기기 시험표

작성일: 2026-11-08. **모든 시험은 아직 실행하지 않았다(미실행).** Mac과 아이폰은 11월 12일(목)부터 일주일 대여 예정이다.
상태 칸: `미실행` / `통과` / `실패(오류 원문과 날짜를 적는다)` / `해당 없음`. 한 항목이 실패하면 뒤 항목으로 넘어가기 전에 원인부터 본다.
"기대 동작" 칸은 코드를 읽어 적은 것이며, 코드 위치가 없는 것은 **기대일 뿐 확인된 사실이 아니다.**
준비물: 시험용 소셜 계정(구글, 카카오, 네이버, 필요하면 애플), 와이파이와 모바일 데이터, 블루투스 심박 센서(있으면), 서버 로그와 Firestore 콘솔 읽기 권한(대표님).

## 기록 방법
각 시험은 날짜, 기기 모델과 iOS 버전, 빌드 번호(`1.0.0 (7)` 등), 결과, 실패 시 오류 원문과 스크린샷을 남긴다. 실행하지 않은 시험은 `미실행`으로 둔다. 통과라고 적으려면 기대 동작이 실제로 관찰돼야 한다.
