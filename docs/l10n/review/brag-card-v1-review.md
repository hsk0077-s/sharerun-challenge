# 번역 검수 요청 — 쉐어런 통합 자랑 카드 (10개 언어)

하상기 님이 이 파일 전체를 **참모 2호 Gemini**와 **참모 4호 ChatGPT**에게 그대로 붙여 넣어 교차 검수를 받습니다.

아래는 한국어 앱 "쉐어런"(걷기·달리기 앱, 회사 자금 기부 연계)의 새 문구 3개를 10개 언어(영어, 일본어, 중국어 번체, 스페인어, 브라질 포르투갈어, 독일어, 프랑스어, 베트남어, 태국어, 인도네시아어)로 번역한 것입니다.
원어민 시각에서 언어별로 검수해 주세요. 이 문구는 달리기 뒤 공유하는 카드 이미지 맨 아래와, 카드에 QR을 넣을지 고르는 스위치에 쓰입니다.

검수 기준:
1. 오역과 누락
2. 어색하거나 그 나라에서 쓰지 않는 표현
3. 한국어에 없는 약속·단정이 들어간 곳 (특히 기부, 보상, 초대 혜택)
4. 카드 이미지의 한 줄이라 길이가 너무 길지 않은지 (2~3줄 안)

지켜야 할 것:
- SHARE, DIA, VALUE, Coach+, ShareRun은 번역하지 않습니다.
- 말투는 친절하고 짧게(앱 화면 문구)입니다.
- "뽑기, 당첨, 랜덤 보상, 토큰, 코인"에 해당하는 말은 쓰지 않습니다.
- QR은 "설치 안내"일 뿐이며, 혜택·보상을 약속하는 표현은 없어야 합니다.

출력 형식 (문제가 있는 항목만, 표로):
| ID | 언어 | 원문(한국어) | 현재 번역 | 문제 | 고친 문장 |
문제가 없는 항목은 적지 말고, 마지막에 "문제 없음: N개"라고만 적어 주세요.

현재 상태: 모두 `native_review: "pending"`(원어민 검수 전)입니다. 검수 뒤에만 이 표시를 지웁니다.
