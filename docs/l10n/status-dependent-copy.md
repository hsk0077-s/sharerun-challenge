# 판매·결제를 열 때 같이 바꿔야 하는 문구 체크리스트

1.0은 앱 안 결제가 없다. 그래서 일부 문구가 "지금은 판매하지 않아요", "준비 중이에요"처럼 **현재 상태**를 말한다. 판매나 결제를 열면 이 문구가 사실과 달라진다. 열기 전에 아래를 한국어와 10개 언어 모두 고친다.

## 1. 앱 스위치 (`--dart-define` 또는 `.env.release`)
| 스위치 | 기본 | 켜면 보이는 것 |
|---|---|---|
| `IN_APP_PURCHASES_ENABLED` | false | Coach+, 구독, DIA 팩, 현금 환불, 후원 결제 화면, 달팽이 도우미의 결제 칩(러너 후원, 구독, Coach+) |
| `DIA_PACKS_ENABLED` | false | 돈으로 사는 DIA (결제 스위치도 켜야 함) |
| `SPONSORSHIP_ENABLED` | false | 이용자 후원(대회 후원, 러너 후원) (결제 스위치도 켜야 함) |
| 서버 `PAYMENTS_ENABLED` | 미설정 | `/health/ready`가 결제 비밀 값을 요구 |

## 2. 달팽이 FAQ (`assets/faq/snail_bot_faq*.json`, 한국어와 10개 언어)
| ID | 지금 하는 말 | 열면 |
|---|---|---|
| AP-08 | 앱 안에서 결제할 일이 없다 | 결제 항목이 생기면 고친다 |
| DI-06 | 다이아를 판매하지 않아 환불할 결제 다이아가 없다 | 환불 규칙(7일, 미사용분) 확정 문구로 |
| DI-07 | 다이아를 판매하지 않는다, 판매를 시작하면 알려 준다 | 구매 방법 안내로 |
| DI-08 | 묶음·가격은 판매 시작 때 알려 준다 | 묶음과 가격을 넣는다 |
| DI-13 | 유료 결제가 열리기 전이라 무료 보상 트랙부터 | 유료 트랙 안내로 |
| CP-01, CP-02 | Coach+는 판매 준비 중, 결제 오픈 전 | 판매 중 문구와 확정 가격으로 |
| CP-05 | 지금은 Coach+를 판매하지 않는다 | 구매 방법으로 |
| CP-10 | 판매 전이라 자동 결제되지 않는다 | 자동 갱신·해지 안내로 |
| CP-07 | 오르막·순위 코칭은 준비 중 | 기능이 생기면 |
| SE-07 | 다이아 결제가 열리면 지문으로 확인 | "열리면"을 "결제 시"로 |

## 3. 달팽이 도우미 (`lib/features/mini_bot/mini_bot_intent.dart`)
- 숨겨진 칩 3개(러너 후원, 구독, Coach+)의 이동 확인·안내 문구는 번역되어 있지만 1.0에서는 보이지 않는다. 열면 금액 문구(`subscriptionAmount`, Coach+ 가격 `6,900원/59,000원`)를 확정 값으로 맞춘다.
- 결제 스위치가 꺼져 있을 때 보이는 "이 버전에서는 앱 안에서 결제하지 않아요."(`mini_bot.body.18`)는 스위치를 켜면 더 이상 나오지 않는다.

## 4. 스토어·법적 문구
| 위치 | 해야 할 일 |
|---|---|
| `store_listings/*` (11개 언어) | "1.0 버전에는 앱 내 유료 결제가 없습니다"(`Version 1.0 includes no paid in-app purchases`) 삭제 또는 수정 |
| `docs/release-notes-*.md` | 출시 노트에 새 기능 안내 |
| `site/terms.html`, `site/privacy.html` | 결제·환불·청약철회 조항, 결제 정보 수집 항목(구매 토큰, 주문 번호) 갱신. 법무 확인 |
| Play Console | 데이터 보안 양식(구매 내역 추가), 구독 상품 등록, 콘텐츠 등급 재확인 (`docs/play-data-safety.md`) |
| 앱 안 약관 동의 화면 | 결제 약관 동의 추가 여부 확인 |
| 다국어 번역 표 (`docs/l10n/remaining-ko-strings.json`) | 판매 문구를 바꾸면 10개 언어를 같이 바꾸고 원어민 검수 |

## 5. 열기 전 확인
1. 서버 `PAYMENTS_ENABLED=true`와 결제 웹훅 비밀 값 설정, `/health/ready` 확인
2. 테스트 구매(Play 라이선스 테스터)로 결제, 환불, 구독 해지 확인
3. 위 FAQ와 스토어 문구가 바뀐 빌드를 먼저 내부 테스트로 확인
4. 그 뒤에 스위치를 켠 빌드를 프로덕션에 올린다
