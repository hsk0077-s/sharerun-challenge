# 쉐어런 문구 이름 규칙

화면에 보이는 문구(알림, 공유 문구, 약관 포함)를 만들 때 이 규칙을 따른다.
규칙을 어기는 표기는 `test/core/naming_rules_test.dart`가 막는다.

## 1. 앱 이름
- 한글은 **쉐어런**(띄어쓰기 없음). 영문은 **ShareRun**.
- 사용자에게 보이는 곳에 개발 약어 **SRC**를 쓰지 않는다. 예: "SRC 워킹챌린지" → "쉐어런 워킹챌린지", 해시태그 `#SRC` → `#쉐어런`.
- "셰어런", "쉐어 런"은 틀린 표기다.

## 2. 통화 이름: SHARE, DIA, VALUE
- 숫자, 잔액, 가격, 버튼, 표에서는 **영문 대문자** 그대로 쓴다. 예: "30 DIA 구매", "보유 SHARE".
- SHARE는 한글로 "셰어", "쉐어"라고 쓰지 않는다(앱 이름과 헷갈리고 표기가 흔들린다). 항상 SHARE.
- 설명 문장 안에서는 "다이아", "밸류"처럼 읽기 쉬운 한글을 쓸 수 있다. 한 문장 안에서 섞어 쓰지 않는다.
- 지갑처럼 처음 설명하는 곳은 "밸류(VALUE)"처럼 한글과 영문을 함께 쓸 수 있다.

## 3. 기능 이름
- 챌린지, 크루, 줍기, 달리기 같은 기능 이름은 한글만 쓴다. 영문 병기는 하지 않는다.

## 4. 쓰지 않는 말
- "토큰", "코인": SHARE는 토큰이나 코인이 아니다. "쉐어토큰"도 쓰지 않는다.
- "완벽한 보안", "해킹 불가", "100% 안전" 같은 과장 표현.
- 기부와 DIA에 우연을 뜻하는 말("뽑기", "당첨", "랜덤 보상")을 붙이지 않는다.

## 5. 예외
- 음성 안내 문구도 SHARE로 쓴다.
- 코드의 클래스 이름, 내부 변수, 개발자용 로그에는 SRC를 쓸 수 있다.
- 서버에서 내려오는 이름(스폰서 이름 등)은 서버 값을 그대로 보여준다.
