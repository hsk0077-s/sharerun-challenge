# Play Console 입력 초안: 데이터 보안 양식, 권한·건강 앱 선언

작성일: 2026-11-01. 근거: `site/privacy.html`(2026-10-24 개정), `AndroidManifest.xml`, `pubspec.yaml`, 서버 코드. **초안이다.** 대표님과 법무가 확인한 뒤 입력한다. 확인이 필요한 곳은 `확인`으로 표시했다.

## 1. 앱이 쓰는 것 (확인한 사실)
- 광고, 분석(Analytics), 크래시 수집 SDK: **없음** (`pubspec.yaml`에 없음). 광고 ID 권한 없음.
- 로그인: 구글, 카카오, 네이버(애플은 미구현). 서버: Firebase(서울 리전), Cloud Run.
- 위치: 정밀·대략 위치, **백그라운드 위치 권한은 없음**(포그라운드 서비스 `health|location`으로 기록).
- 건강: Health Connect에서 **걸음 수와 심박수만 읽음**, 쓰기 없음, 백그라운드 읽기 권한 제거됨.
- 마이크(달팽이봇 말하기), 카메라(완주 카드 사진), 알림(FCM).
- `in_app_purchase` 패키지가 들어 있어 결제 권한이 병합될 수 있다. 1.0은 결제 비활성.

## 2. 데이터 보안 양식 답변

**공통**
| 질문 | 답 |
|---|---|
| 앱이 사용자 데이터를 수집하거나 공유하나요 | 예 |
| 전송 중 암호화 | 예 (HTTPS) |
| 사용자가 데이터 삭제를 요청할 수 있나요 | 예. 앱 안 `설정 > 계정 삭제`, 웹: `https://share-run-challenge.web.app/account-deletion.html` |
| 제3자 공유 | **아니요** (처리 위탁인 Google/Firebase는 "공유"가 아님). 확인: 구글 지도·음성 인식이 위탁에 해당하는지 |
| 독립 보안 검토 | 아니요 |

## 3. 권한 선언과 사용 설명
| 권한 | 용도 | 비고 |
|---|---|---|
| `ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION` | 러닝 경로·거리 기록과 검증, 지도 | |
| `FOREGROUND_SERVICE_LOCATION`, `FOREGROUND_SERVICE_HEALTH` | 화면을 꺼도 달리기 기록이 끊기지 않게 | Play가 **포그라운드 서비스 사용 설명과 시연 영상**을 요구한다. 달리기 시작 → 화면 끔 → 알림에 "기록 중" 표시 → 종료 흐름을 영상으로 |
| `ACTIVITY_RECOGNITION` | 만보기(걸음 수) | |
| Health Connect `READ_STEPS`, `READ_HEART_RATE` | 걸음 수, 달리기 중 심박 표시와 검증 | 개인정보처리방침에 Health Connect Limited Use 문구가 이미 있음 |
| `RECORD_AUDIO` | 달팽이봇 말하기 | 누를 때만 사용 |
| `CAMERA` | 완주 카드 배경 사진 | 선택 |
| `BLUETOOTH_CONNECT` 등 | 심박 센서·워치 연결 | |
| `POST_NOTIFICATIONS`, `RECEIVE_BOOT_COMPLETED` | 알림, 알림 예약 복원 | |
| (제거됨) `BODY_SENSORS`, 백그라운드 위치, 백그라운드 건강 읽기, 생체 인증 | | 선언 불필요 |

## 4. 앱 콘텐츠 선언 (예상 답변)
- **광고 포함 여부**: 아니요.
- **정부 앱, 금융 기능, 뉴스 앱**: 아니요.
- **건강 앱**: 예. 건강 및 피트니스 앱으로 분류하고 위 Health Connect 사용을 설명한다. 의료 기기나 진단 기능은 없다.
- **콘텐츠 등급 설문**: 사용자 생성 콘텐츠(닉네임, 크루 이름, 신고) 있음, 위치 공유 없음(다른 사용자에게 보이지 않음. 확인), 도박·실제 돈 상금 없음, 결제 없음.
- **타깃 연령**: 가입 연령 만 14세 이상. Play 연령대 선택에서 **13–15세를 포함할지** 정해야 한다. 포함하면 청소년 관련 추가 요건이 붙는다. 확인.
- **계정 삭제 URL**: `https://share-run-challenge.web.app/account-deletion.html`

## 5. 대표님이 확인할 것
1. 건강 정보(심박수)를 "수집"으로 표시할지(원본 미저장이라 면제도 가능하지만, 보수적으로 표시하면 반려 위험이 낮다).
2. 구글 지도, 기기 음성 인식을 "공유"로 볼지 "처리 위탁"으로 볼지. 권장은 위탁(공유 아님).
3. 타깃 연령 13–15세 포함 여부.
4. 포그라운드 서비스 시연 영상 촬영(S23, 약 30초).
5. 결제를 열 때(구매 내역, 환불 등) 이 문서와 개인정보처리방침을 같이 갱신.
