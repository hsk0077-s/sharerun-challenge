# 구글 플레이 스토어 등록 초안

코드와 방침(`site/privacy.html`)에서 확인한 사실로 채운 **초안**이다. `[확인]`은 사람이 맞는지 봐야 한다.
구글 양식의 문항 이름은 바뀔 수 있으니 콘솔 화면의 실제 문구를 우선한다.

## 1. 스토어 등록정보

| 항목 | 제한 | 초안 |
|---|---|---|
| 앱 이름 | 30자 | 쉐어런 - 함께 달리는 러닝 챌린지 |
| 간단한 설명 | 80자 | 달리고 걸을수록 쌓이는 보상. 크루와 함께 도전하는 러닝 챌린지 앱 |
| 아이콘 | 512×512 PNG | `[준비 필요]` |
| 그래픽 이미지 | 1024×500 | `[준비 필요]` |
| 스크린샷 | 휴대전화 2~8장 | `[준비 필요]` 홈, 달리기 기록, 크루, 완주 카드, 마스코트 |

자세한 설명(4,000자 이내) 초안:

```
쉐어런은 걷고 달린 기록이 보상이 되는 러닝 챌린지 앱입니다.

■ 달리기·걷기 기록
- GPS로 거리, 시간, 평균 속도, 경로를 기록합니다. 화면을 꺼도 기록이 이어집니다.
- 킥보드·자전거·차량으로 이동한 기록은 자동 검증으로 걸러집니다.
- 완주 카드로 오늘의 기록을 사진처럼 남기고 공유할 수 있습니다.

■ 하루 걸음 수
- Health Connect의 걸음 수를 읽어 만보기 보상을 줍니다.

■ 크루와 챌린지
- 크루를 만들거나 가입해 함께 달리고, 월간 크루 랭킹에 도전합니다.
- 대회와 챌린지에 참가해 순위를 겨룹니다.

■ 나만의 마스코트
- 달팽이 마스코트와 액세서리를 꾸미고, 달리는 동안 음악을 들을 수 있습니다.

■ 알려드립니다
- 위치는 달리기 기록 중에만 사용합니다.
- 심박수와 걸음 수는 별도 동의 후에만 읽습니다.
- 앱 안 결제(다이아, 구독)는 구글 플레이 결제로 진행되며, 구매한 다이아의 환불은 구입 후 7일 안에 신청할 수 있습니다.
- 만 14세 이상만 가입할 수 있습니다.
```

> 설명에 "기부"나 특정 단체 이름은 넣지 않았다. 후원(스폰서)은 보류 중이고 수혜 단체도 정해지지 않았다.
> 실제로 앱에 있는 기능만 적는다. 광고 문구(최고, 1위 등)는 증빙이 필요하니 피한다.

## 2. 데이터 보안(Data safety) 설문 답안

원칙: 구글이 말하는 "수집"은 앱이 서버로 보내 저장하는 것이다. 기기 안에서만 쓰는 정보는 수집이 아니다.
"공유"는 제3자에게 넘기는 것이며, 앱을 운영하려고 맡기는 서비스 제공업체(Firebase 등)는 공유에 넣지 않는다 `[확인]`.

| 구글 분류 | 항목 | 수집 | 필수/선택 | 목적 | 비고 |
|---|---|---|---|---|---|
| 개인 정보 | 이메일 주소, 사용자 ID | 예 | 필수 | 계정 관리, 앱 기능 | 구글·카카오·네이버 로그인 `[이름·프로필 사진을 받는지 확인]` |
| 위치 | 대략적 위치, 정확한 위치 | 예 | 필수 | 앱 기능(러닝 기록), 부정 이용 방지 | 출발·도착 300m 구간은 저장하지 않음 |
| 건강 및 피트니스 | 건강 정보(심박수) | 예 | **선택(동의 시)** | 러닝 검증 | 원본 값은 서버에 저장하지 않음 |
| 건강 및 피트니스 | 피트니스 정보(운동, 거리, 걸음 수) | 예 | 필수 | 앱 기능 | |
| 금융 정보 | 구매 내역 | 예 | 선택 | 결제 확인, 재화 지급 | 카드 정보는 구글이 처리하며 앱은 받지 않음 |
| 사진 및 동영상 | 사진 | 예 | **선택** | 소명(이의 제기) 증빙 | 결정 즉시 또는 14일 후 삭제. 완주 카드 사진은 서버로 보내지 않음 |
| 앱 활동 | 앱 내 활동 | 예 | 필수 | 앱 기능 | 크루·대회·재화 기록 |
| 기기 또는 기타 ID | 푸시 토큰, 기기 모델·OS 정보 | 예 | 필수 | 알림, 계정 보호 | `[기기 고유 ID를 따로 받는지 확인]` |
| 오디오 | 음성 | **아니오** | - | - | 달팽이봇 말하기는 휴대폰의 음성 인식이 처리하며 앱은 음성을 저장하지 않음 `[구글 해석 확인]` |
| 앱 정보 및 성능 | 비정상 종료 기록 | 아니오 | - | - | 분석·비정상 종료 도구 없음(pubspec 확인) |

공통 질문:
- 전송 중 데이터 암호화: **예**(HTTPS).
- 이용자가 삭제를 요청할 수 있나: **예**. 앱 안(마이 → 계정 삭제)과 웹 `https://share-run-challenge.web.app/account-deletion.html`.
- 광고: 광고 SDK 없음 → "광고를 포함하지 않음".
- 데이터를 판매하나: **아니오**. 광고·분석 목적 제3자 공유: **아니오**.

## 3. 권한·민감한 앱 콘텐츠 선언

| 선언 | 답안 방향 |
|---|---|
| 위치 권한 | 달리기 GPS 기록. 백그라운드 위치(항상 허용)는 쓰지 않음 |
| 포그라운드 서비스 유형(위치, 건강) | 화면을 꺼도 달리기·걸음 기록이 끊기지 않게 하는 지속 알림 |
| Health Connect | 걸음, 심박, 거리, 운동, 활동 칼로리, 활동 강도 읽기. `READ_HEALTH_DATA_IN_BACKGROUND`는 화면이 꺼진 동안 걸음을 읽기 위해 필요 → 선언에서 이유를 설명 (`docs/play-release.md` 3항) |
| 신체 활동, 센서 | 만보기, 심박 센서 `[센서 권한이 꼭 필요한지 폰에서 확인]` |
| 카메라, 마이크 | 완주 카드 배경 사진, 달팽이봇 말하기(누를 때만) |

## 4. 앱 안 상품 (콘솔의 "수익 창출 → 제품"에 등록)

앱을 처음 올린 뒤에야 등록할 수 있다. 상품 ID는 코드와 **글자 하나도 다르면 안 된다**.

| 종류 | 상품 ID | 가격(원) | 내용 |
|---|---|---|---|
| 소모성 | `dia_pack_12` | 1,200 | 12 DIA |
| 소모성 | `dia_pack_60` | 5,900 | 59 + 보너스 1 |
| 소모성 | `dia_pack_130` | 12,000 | 120 + 보너스 10 |
| 소모성 | `dia_pack_370` | 33,000 | 330 + 보너스 40 |
| 소모성 | `dia_pack_700` | 59,000 | 590 + 보너스 110 |
| 소모성 | `dia_pack_1500` | 119,000 | 1,190 + 보너스 310 |
| 구독 | `coach_plus_monthly` | 6,900 | 월간 |
| 구독 | `coach_plus_yearly` | 59,000 | 연간 |
| 소모성 | `share_pack_*` | 10,000~ | SHARE 팩 `[아직 판매할 상품인지 확인]` |

`[확인]` 디지털 재화는 구글 플레이 결제로만 판매해야 한다. 앱 밖 결제로 유도하는 문구는 넣지 않는다.

## 5. 앱 콘텐츠 양식

- **개인정보처리방침 URL**: `https://share-run-challenge.web.app/privacy.html`
- **타깃 연령층**: 앱의 가입 기준은 **만 14세 이상**이다. 콘솔의 연령 구간은 13~15세, 16~17세, 18세 이상으로 나뉘므로 13~15세를 고르면 13세가 포함되는 점이 맞지 않는다. 16~17세와 18세 이상만 고르면 정책과 맞는다 `[확인]`. 어린이 대상 앱(가족 정책)으로 분류되지 않도록 어린이 구간은 고르지 않는다.
- **광고 포함 여부**: 아니오
- **앱 액세스**: 로그인이 필요하므로 심사용 테스트 계정(구글 계정 로그인)과 사용 방법을 적어야 한다 `[준비 필요]`
- **콘텐츠 등급 설문**: 폭력·성적 내용·도박 없음. 앱 안 구매 있음. 이용자 간 소통(크루 닉네임) 있음
- **금융 기능, 뉴스, 정부 앱, 건강 앱**: 의료 진단·치료를 주장하지 않는 "피트니스" 앱으로 답한다 `[확인]`
