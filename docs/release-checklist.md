# 출시 전 점검표

출시 전에 반드시 끝내거나 결정해야 하는 일을 한 곳에 모은 목록입니다.
끝낸 항목은 `[x]`로 바꾸고 날짜와 PR 번호를 적습니다.

## 1. 꼭 해야 하는 일 (출시 막힘)

- [x] **계정 연결 정상화(카카오·네이버)** — 2026-10-13 완료(#247, #248, #252, #253). 구글·카카오·네이버가 같은 계정으로 이어지고 연결·해제까지 폰에서 확인했다.
  - 남은 것: 카카오 전용 계정에서 구글을 연결하는 기능, 애플(iOS 출시 때), "내 폰 로그아웃만"(폰별 로그아웃).
- [ ] **네이버 로그인 점검**
  - 서버가 네이버 토큰이 우리 앱용인지 확인할 방법이 없다(카카오는 앱 번호로 확인함). 새 가입을 허용하기로 정했으므로, 출시 전에 이 약점을 다시 판단한다.
  - 네이버 개발자센터 API 설정의 "제공 정보"에서 회원이름·이메일·프로필 사진이 **필수**로 되어 있다. 앱은 쓰지 않으므로 최소로 줄인다.
  - **릴리스 빌드**(`--release`)에서 네이버 연결과 로그인이 되는지 확인한다(코드 최적화 규칙 추가 후 첫 확인).
  - 네이버 앱이 "개발 중"이면 개설자·테스터만 로그인할 수 있다. 출시 전에 검수를 받는다.
- [ ] **구글 플레이 콘솔과 클라우드 프로젝트 연결** — 기기 확인(Play Integrity)이 정상 값을 돌려주는 조건이다. 연결 뒤 `integrityChecks`에 `device` 값이 생기는지 확인한다.
- [ ] **결제 영수증 서버 검증(Coach+)** — 플레이 콘솔이 준비된 뒤 서버에서 영수증을 확인한다. 이전에는 결제를 받지 않는다.
- [ ] **법무 검토** — 약관, 개인정보처리방침, 기부·SHARE·VALUE 관련 표현.
- [ ] **iOS 출시 준비** — 애플 로그인(위 계정 연결 이후), 앱스토어 심사 항목.

## 2. 출시 전에 마무리할 일

- [x] **소명(이의 제기) 운영** — 관리자 웹에서 증빙 사진을 보고(열람 기록 남음) 승인·기각한다. 승인하면 달리기가 인정된 기록으로 한 번만 정산되고, 결정하면 증빙은 즉시 삭제된다(결정이 없으면 14일 뒤 자동 삭제). 대회 기록의 대회 보상, 반납한 보증금은 승인해도 되돌리지 않는다.
- [ ] 자전거·킥보드 활동도 소명 대상에 넣을지 정한다.
- [ ] **카카오 공유 카드** — 이름과 아이콘을 정리한다.
- [ ] **Firebase App Check 도입 여부** — 앱이 아닌 곳에서 서버를 부르는 것을 줄일지 정한다.
- [x] **카카오 로그인 버튼 글씨** — 자리 너비에 맞춰 비율을 지키며 높이가 공식 높이(46)에 가까운 이미지를 고르도록 고쳤다(넓은 폰에서 38까지 줄어 글자가 작아 보이던 문제).
- [x] **달팽이봇 소개 문구** — "궁금한 걸 물어보세요"로 바꿨다. 추천 질문 칩도 짧은 이름으로 바꿨다.

## 3. 정해 둔 것 (바꾸지 않는 약속)

- 로그인은 **구글·카카오·네이버**를 쓴다. 애플은 iOS 출시 때 연다.
- 티어 동물은 **돈으로 살 수 없다.** 등급이 없으면 달팽이를 보여 준다.
- 달팽이봇 이름은 "달팽이봇"이고 "AI"라는 말을 붙이지 않는다.
- 앱은 서버가 확인한 값만 보여 주고, 기록은 지우지 않고 덧붙이는 방식이다.
- 완벽한 보안을 약속하는 표현은 쓰지 않는다.
