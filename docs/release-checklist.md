# 출시 전 점검표

출시 전에 반드시 끝내거나 결정해야 하는 일을 한 곳에 모은 목록입니다.
끝낸 항목은 `[x]`로 바꾸고 날짜와 PR 번호를 적습니다.

## 1. 꼭 해야 하는 일 (출시 막힘)

- [ ] **계정 연결 정상화** — 카카오·네이버·애플 로그인을 열기 **전에** 먼저 끝낸다.
  - 지금은 구글만 쓰고, 카카오·네이버는 Firebase를 거치지 않는다.
  - 같은 사람이 다른 방법으로 로그인해도 지갑·기록이 하나로 이어져야 한다. 이어지지 않으면 데이터가 사라진 것처럼 보인다.
  - 방법을 정할 때 "내 폰 로그아웃만"(폰별 로그아웃)도 함께 정한다.
- [ ] **구글 플레이 콘솔과 클라우드 프로젝트 연결** — 기기 확인(Play Integrity)이 정상 값을 돌려주는 조건이다. 연결 뒤 `integrityChecks`에 `device` 값이 생기는지 확인한다.
- [ ] **결제 영수증 서버 검증(Coach+)** — 플레이 콘솔이 준비된 뒤 서버에서 영수증을 확인한다. 이전에는 결제를 받지 않는다.
- [ ] **법무 검토** — 약관, 개인정보처리방침, 기부·SHARE·VALUE 관련 표현.
- [ ] **iOS 출시 준비** — 애플 로그인(위 계정 연결 이후), 앱스토어 심사 항목.

## 2. 출시 전에 마무리할 일

- [ ] **소명(이의 제기) 운영** — 관리자가 증빙 사진을 볼 수 있게 하고, 자전거·킥보드 활동도 소명 대상에 넣을지 정한다. 증빙은 14일 뒤 자동 삭제된다.
- [ ] **카카오 공유 카드** — 이름과 아이콘을 정리한다.
- [ ] **Firebase App Check 도입 여부** — 앱이 아닌 곳에서 서버를 부르는 것을 줄일지 정한다.
- [ ] **달팽이봇 소개 문구** — "안내 → 추천 → 확인 → 실행"을 "궁금한 걸 물어보세요" 같은 쉬운 말로 바꿀지 정한다.

## 3. 정해 둔 것 (바꾸지 않는 약속)

- 로그인은 지금 **구글만**. 카카오·네이버·애플은 계정 연결 뒤에 연다.
- 티어 동물은 **돈으로 살 수 없다.** 등급이 없으면 달팽이를 보여 준다.
- 달팽이봇 이름은 "달팽이봇"이고 "AI"라는 말을 붙이지 않는다.
- 앱은 서버가 확인한 값만 보여 주고, 기록은 지우지 않고 덧붙이는 방식이다.
- 완벽한 보안을 약속하는 표현은 쓰지 않는다.
