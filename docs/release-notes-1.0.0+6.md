# 출시 노트 1.0.0 (버전 번호 +6)

Play Console "새로운 기능"에 붙여 넣는 글입니다. 한국어·영어 각 3줄.
기부는 아직 송금 실적이 없어서 "기부 예정"으로만 씁니다. 기부처 이름은 쓰지 않습니다.
+5 대비 변경: 구글 로그인 설정 누락을 빌드에서 막았습니다(앱 기능 변화 없음, 문구 변경 없음).

## 한국어 (ko-KR)
```text
달리기와 걷기를 인증하면 SHARE가 쌓여요. 첫 인증 1km에 거북이 브론즈로 시작해 인증된 날마다 한 단계씩 올라가요.
Health Connect에서는 걸음 수만 읽어요. 심박수는 블루투스 심박 센서를 연결했을 때만 받아요.
회사(운영자) 자금으로 인증 1km당 100원을 기부할 예정이에요. 내가 내는 돈은 없어요.
```

## English (en-US)
```text
Verified runs and walks earn SHARE. You start as Turtle Bronze after your first verified 1 km, then move up one step on each verified day.
The app reads only step counts from Health Connect. Heart rate is received only from a Bluetooth heart-rate sensor you connect.
The company (operator) plans to donate 100 KRW per verified km from its own funds. You pay nothing.
```
