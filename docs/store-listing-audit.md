# Play 스토어 설명문 점검 (11개 언어)

점검일: 2026-11-01. 대상: `store_listings/*/store-listing.md` 11개. 코드(`lib`, `backend`)와 `site/privacy.html`을 기준으로 사실과 맞는지 확인했다.

## 이번에 고친 것 (안드로이드 설명문에서 사실과 다른 표현)
| 항목 | 내용 | 이유 |
|---|---|---|
| 로그인 목록의 **Apple** (ko) | `Google, Apple, Kakao, Naver` → `Google, Kakao, Naver` | 애플 로그인은 아직 구현되지 않았다. 없는 기능을 소개하면 오해 소지 표시 대상이다. |
| **Apple Watch, Apple Health(HealthKit)** (11개 언어 모두) | 설명문과 출시 노트에서 삭제, Google Health Connect 기준으로 정리 | 안드로이드 앱은 애플워치·애플 건강과 연동되지 않는다. Play 설명문은 안드로이드 기준이어야 한다. 애플 앱 설명문을 만들 때 다시 넣는다. |
| **"AI 달팽이봇"** (ko, ja) | `AI` 삭제 | 달팽이봇의 FAQ 답변은 미리 써 둔 문장이고 생성형 AI가 아니다. |
| 글자 수 표기 | 11개 파일의 `Full Description (n/4000 chars)` 갱신 | 수정으로 길이가 바뀜 |

글자 수 제한(제목 30, 짧은 설명 80, 전체 4000)은 11개 언어 모두 지킨다.

## 맞는 것으로 확인한 것
- 100걸음=10 SHARE, 하루 600 SHARE(6,000걸음), 검증 1km당 100원, 1인 하루 10km, 월 100만 원 한도: 11개 언어 모두 같은 숫자.
- "기부 예정", 기부처 협의 중, 세금 공제 영수증 없음, 현금 환급 불가, 1.0은 앱 내 유료 결제 없음: 11개 언어 모두 들어 있다.
- 유니세프(UNICEF) 언급 없음.
- 출발·도착 근처 경로 가림: 서버가 저장할 때 출발·도착에서 300m를 빼므로(`route_privacy.py`) "자동으로 가림" 표현은 맞다.

## 대표님 판단이 필요한 것 (고치지 않음)
1. **"나눔 매칭 / charity matching pools"** (ko 소제목 `투명한 나눔 매칭`, en 도입부, ja·de 소제목): "매칭"이라는 말은 이용자 돈에 맞춰 기부한다는 뜻으로 읽힐 수 있다. "기부 예정" 원칙과 거리가 있다. 예: `투명한 나눔 안내`, `Planned charity giving`.
2. **(수정함)** **달팽이 FAQ의 보안 항목 3개가 앱에 없는 기능을 말했다** (한국어 원본 문제, 번역도 같음):
   - SE-01 "…공개 범위 설정 같은 기능이 있어요": 앱에 공개 범위 설정 화면이 없다.
   - SE-09 "기록 공개 범위는 기본이 '나만 보기'예요. 원하실 때만 바꾸시면 돼요": 바꾸는 기능이 없다.
   - SE-10 "집 근처 경로를 가리는 기능이 있어요. 보안 센터에서 설정해 주세요": 가림은 자동이고 설정 화면은 없다.
   - 제안: SE-10을 "달리기 경로는 저장할 때 출발·도착에서 가까운 300m를 빼고 보관해요. 따로 설정할 필요는 없어요."로, SE-01·SE-09에서 공개 범위 문구를 삭제. 확정하면 한국어와 10개 언어를 함께 고친다.
3. **"1K, 3K, 5K, 10K 대회"** 표현: 실제 방 거리는 1·2·3·5·10km이고 회사 대회는 초급·중급·상급·하프·파이널이다. 큰 오류는 아니지만 고칠 수 있다.
4. **"차량·오토바이·기계 흔들기를 걸러내고 정직한 땀방울만 인정"**: 단정에 가깝다. "…걸러내도록 설계했습니다" 정도로 낮출 수 있다.
5. 가입 연령(만 14세 이상) 문구는 한국어 설명에만 있다. 다른 언어에도 넣을지 결정.
