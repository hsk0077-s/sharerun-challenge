# 티어·대회 규칙 (확정안 2026-10-15) 와 구현 상태

대화에서 확정한 규칙을 서버 코드와 맞춘 기록입니다. 숫자는 전부 제안값이고 서버 설정으로 바꿉니다.

## 규칙 요약
- 첫 등급: 서버가 검증한 1km 이상 러닝 3번(서로 다른 날)의 중간 페이스로 동물+메달 한 번에 정함. (기존 그대로)
- 그 뒤에는 **대회 성적으로 모은 승급 점수**로 메달 한 칸씩 올라감. 메달 5칸을 채우면 다음 동물.
- 대회는 **자유 대회**(누구나, 점수 0.5배)와 **티어 대회**(동물 등급별, 점수 전액) 두 종류.
- 한 단계 위 티어 대회는 **도전 입장권**(번 SHARE 1,200 또는 무료 다이아 1개)으로 주 1회. 하위 대회는 입장 불가.
- 승급 점수 = 순위 점수 × 참가 인원 배수 × 대회 종류 배수. 5명 미만이면 0점.
- 강등은 시즌 끝에 활동이 없을 때만 메달 한 칸. 승급 보상은 칭호와 참가 자격뿐(현금·DIA 없음).

## 구현된 서버 (backend/jena_ai)
| 기능 | 파일 | 메모 |
|---|---|---|
| 승급 점수 계산·메달 승급·원장 | `app/services/promotion_points.py` | `config/promotion`으로 숫자 조정. `promotionLedger/{대회}__{uid}` 한 번만 기록 |
| 회사 공식 대회 정산에 연결 | `company_tournament_settlement.py` | 정산 후 점수 지급(실패해도 상금 정산은 유지) |
| 도전 입장권 구매 | `app/services/challenge_tickets.py` | `POST /shop/purchase` `itemId=challenge_ticket`, `payWith=share|dia`. 유료 다이아·잠긴 추천 SHARE 불가 |
| 티어/자유 대회 입장·완주 기록·정산 | `app/services/ranked_tournaments.py` | 대회 문서 `kind=tier|free`, `tierAnimal=1..5`. 운영 API: `POST /ops/ranked-tournaments/{id}`, 정산은 기존 `/ops/tournaments/{id}/settle` |

## 아직 안 한 것 (이유)
- **시즌 강등**: 시즌 경계(3개월)와 "인증 러닝 0회" 집계 작업이 필요. 별도 작업.
- **말 → 치타 승급**: "시즌 상위 10%" 기준 데이터가 없어서 점수가 차도 대기 상태(`blocked: season`).
- **늑대 이상 즉시 승급 1등**: 확정안에 "시행 전 재검토"로 남아 있어 거북·말티즈만 적용.
- **월간 챌린지(10월 누적 20km)**: 규칙 문서에 없음. 목표 거리·순위 계산 확정 필요.
- **유저가 만드는 자유 대회 생성 화면·앱 연결**: 앱(Flutter) 쪽 목록·입장권 시트·승급 점수 표시는 서버 API 배포 뒤에 연결.
- 배포: Cloud Run 재배포와 `firestore.rules` 배포가 필요(대표님 배포 단계).
